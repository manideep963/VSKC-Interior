# VSKC Interiors - Best Interior Designers in Hyderabad

A high-converting, modern, responsive website for **VSKC Interiors**, Hyderabad's premier turnkey residential interior design and execution firm.

## 🌟 Key Features

- **Full Multi-Page Website Architecture:**
  - `index.html` - Comprehensive Hero landing page, instant lead capture form, stats counter, services preview, interactive space & scope planner, filterable portfolio gallery, why choose us, VSKC Interiors vs Local Contractors comparison matrix, 4-step execution process, material brand partners ticker, customer reviews & testimonials, FAQ accordion, call to action banner, and footer.
  - `about.html` - Our story since 2017, design philosophy, 10-year warranty, German precision machinery factory overview, and Kukatpally Experience Center tour details.
  - `services.html` - In-depth breakdown of Modular Kitchens, Custom Wardrobes, Living & Dining Units, False Ceilings & Lighting, Sacred Pooja Mandirs, and Turnkey 2BHK/3BHK Makeovers.
  - `portfolio.html` - Interactive filterable gallery showcasing real projects across Hyderabad (Kukatpally, HITEC City, Gachibowli, Tellapur, Kokapet, Miyapur, Nallagandla).
  - `packages.html` - Structured interior design packages (2BHK Essential, 2/3BHK Premium, and 3BHK/Villa Luxury) detailing scope of work, material grades, hardware, and handover timelines.
  - `contact.html` - Full contact directory, Kukatpally Experience Center address, direct phone numbers, email, showroom timings, interactive inquiry form, and Google Maps location button.

- **Interactive Capabilities:**
  - Dynamic 2BHK/3BHK/Villa Space & Scope Planner with live room configuration and material tier specifications.
  - Category-based portfolio filter tabs (All, Kitchens, Living, Wardrobes, Ceilings, Pooja Rooms).
  - Modal lead capture popup with animated submission states and toast notifications.
  - Responsive mobile drawer navigation with hamburger toggle.
  - Quick WhatsApp chat button and back-to-top scroll button.
  - Clean styling utilizing Google Fonts (*Playfair Display* & *Plus Jakarta Sans*) and FontAwesome 6 icons.

## 🚀 How to Run & Preview

You can open `index.html` directly in any web browser, or launch a lightweight local server:

### Option 1: Direct Double Click
Simply double click on `index.html` to open it in your default web browser (Chrome, Edge, Firefox).

### Option 2: Python Local Server
Run the following in PowerShell from this directory:
```powershell
python -m http.server 8080
```
Then open: [http://localhost:8080](http://localhost:8080)
